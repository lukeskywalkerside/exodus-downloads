Mac test installers for EXODUS 3.3.9.

Choose **arm64** for Apple Silicon (M1 and later) or **x64** for an Intel Mac. Requires macOS 11 or later.

Open the DMG and drag EXODUS into Applications. Choose **Connect existing wallet** to connect an existing Windows or web account using its 12 recovery words.

These test builds have ad-hoc signatures. They are not Apple Developer ID signed or notarized; macOS may block opening them. Updates are manual.

Both variants passed launch, account entry, native menu and window reopening checks on matching Mac build machines. SHA-256 checksums are attached.
