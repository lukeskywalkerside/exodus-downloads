# EXODUS Mac downloads

Mac test installers for EXODUS 3.3.9 are available in [Releases](https://github.com/lukeskywalkerside/exodus-downloads/releases).

- **Apple Silicon**: M1 and later Macs (`arm64`)
- **Intel Mac**: `x64`
- Requires macOS 11 or later.

Open the DMG and drag EXODUS into Applications. To open an existing account, choose **Connect existing wallet** and enter the existing 12 recovery words from Windows or the web app.

These are test builds with ad-hoc signatures. Apple Developer ID signing and notarization are not included, so macOS may block opening them. Mac updates are manual in this version.

Both architectures passed automated launch, account entry, native menu and window reopening checks on matching Mac build machines. Real-account testing on a user's Mac remains to be done.

Checksums are included with the release.
